# 국기 맞추기 게임 (Flag Quiz Game)

랜덤으로 표시되는 국기를 보고 국가를 맞추는 퀴즈 게임입니다.

## 데모 링크 (Demo)

https://eziquexx.github.io/mini-random-flag-quiz/

## 기술 스택 (Tech Stack)

| 분야 | 사용 기술 |
|------|-----------|
| Frontend | React · Vite · JavaScript |
| Deployment | GitHub Pages |
| Version Control | Git · GitHub |

## 주요 기능 (Features)

- 랜덤 국기 문제 생성
- 정답/오답 판정
- 점수 계산 및 결과
- 게임 재시작

## 프로젝트 구조 (Project Structure)

```
src
├── components  # 재사용 UI 컴포넌트
├── layouts     # 공통 레이아웃
├── pages       # 페이지 컴포넌트
├── routes      # 라우팅 설정
├── utils       # 유틸 함수
└── data.json   # 국기 데이터
```

## 회고 (Learnings)

- React의 useState를 활용한 상태 관리 경험
- 랜덤 문제 생성 로직 구현
- JSON 기반 데이터 관리 경험
- GitHub Pages를 활용한 정적 웹사이트 배포 경험
